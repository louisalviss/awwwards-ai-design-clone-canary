The stack is multiplying: general models, visual generators, coding agents, prototypes and small custom tools now coexist in one design process.

The winning pattern is not using everything. It is arranging tools around a clear creative decision loop and knowing which decisions still require judgment.

02 / CRAFT

Craft in the age
of abundant output

When execution gets cheap, selection gets expensive. Taste, editing and system thinking become more visible—not less.

Prototyping can happen continuously, but quality still depends on a strong point of view and on recognizing when generated output is merely plausible.
